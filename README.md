# PromotionPlanner

مخطط الترقيات 2027–2031. تطبيق متصفح ثابت مع استيراد وتصدير Excel وحفظ محلي في localStorage.

## أعمدة Excel
اسم الموظف، الرقم الوظيفي، الدرجة الحالية، تاريخ آخر ترقية.

التواريخ المقبولة: YYYY-MM-DD أو DD/MM/YYYY أو تواريخ Excel.

## ملاحظات
- لا ترفع ملفات الموظفين إلى GitHub.
- بيانات المتصفح محلية لكل جهاز/متصفح؛ امسح بيانات المتصفح فتفقدها ما لم تحفظ نسخة احتياطية.
- استيراد Excel يتطلب اتصالا بالإنترنت لتحميل مكتبة SheetJS من CDN.
- حساب الاستحقاق تقديري وفق دورة السنوات وفروق الدرجات القابلة للتعديل، ولا يعني اعتماد الترقية.
- حالات الترقيات محفوظة محليا. لا يحل محل المراجعة والاعتماد الرسمي.
- تفعيل GitHub Pages: Settings > Pages > Build and deployment > GitHub Actions.
